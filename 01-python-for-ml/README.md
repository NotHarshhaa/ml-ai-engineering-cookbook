# Module 01 — Python for Machine Learning

The foundation module. Every later notebook assumes the Python, NumPy, Pandas,
and visualisation fluency built here.

| Notebook                       | Topic                                                                   | Code walkthrough                                                                   |
|--------------------------------|-------------------------------------------------------------------------|------------------------------------------------------------------------------------|
| `01_python_essentials.ipynb`    | Python data structures, functions, classes — the language of ML code.   | [README_01_python_essentials.md](README_01_python_essentials.md)                    |
| `02_numpy_fundamentals.ipynb`   | n-d arrays, vectorisation, broadcasting, linear algebra.                | [README_02_numpy_fundamentals.md](README_02_numpy_fundamentals.md)                 |
| `03_pandas_fundamentals.ipynb`  | DataFrames, group-by, joins, reshaping, missing data.                   | [README_03_pandas_fundamentals.md](README_03_pandas_fundamentals.md)               |
| `04_statistics.ipynb`          | Descriptive stats, distributions, hypothesis tests, confidence intervals.| [README_04_statistics.md](README_04_statistics.md)                                |
| `05_visualization.ipynb`       | Matplotlib, Seaborn, the four diagnostic plots every model needs.        | [README_05_visualization.md](README_05_visualization.md)                            |

Every notebook follows the cookbook's 10-point learning structure:
Concept Overview → Math → From-Scratch → Library → Dataset → Viz → Eval →
Experiments → Challenges → Interview Questions.

Each notebook has a companion `README_<notebook-name>.md` that walks through
every code cell — open it alongside the notebook if you want a written
explanation of what each block does and why.
