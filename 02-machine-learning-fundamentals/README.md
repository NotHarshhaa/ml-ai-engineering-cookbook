hypothesis classes, loss functions, optimisers, and gradient descent.

| `03_optimizers.ipynb`         | GD, momentum, Nesterov, AdaGrad, RMSProp, Adam — with trajectory plot.| [README_03_optimizers.md](README_03_optimizers.md)           |
