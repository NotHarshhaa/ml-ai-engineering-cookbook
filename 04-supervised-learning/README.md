# Module 04 — Supervised Learning

The workhorses of tabular ML: linear and logistic regression, decision trees,
random forests.

| Notebook                        | Topic                                                                  | Code walkthrough                                            |
|---------------------------------|------------------------------------------------------------------------|-------------------------------------------------------------|
| `01_linear_regression.ipynb`   | OLS, Ridge, Lasso, ElasticNet — closed form and gradient descent.     | [README_01_linear_regression.md](README_01_linear_regression.md) |
| `02_logistic_regression.ipynb` | Binary + multinomial, cross-entropy, ROC/PR, calibration.              | [README_02_logistic_regression.md](README_02_logistic_regression.md) |
| `03_decision_trees.ipynb`      | Gini, entropy, recursion, pruning, bias-variance vs depth.            | [README_03_decision_trees.md](README_03_decision_trees.md)   |
| `04_random_forest.ipynb`       | Bagging + feature sub-sampling, OOB error, permutation importance.    | [README_04_random_forest.md](README_04_random_forest.md)     |

Each notebook has a companion `README_<notebook-name>.md` that walks through
every code cell — open it alongside the notebook if you want a written
explanation of what each block does and why.
